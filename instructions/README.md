# Attendee instructions

A self-paced path through the three BRK231 demos: build a conversational agent in Microsoft
Copilot Studio, optimize an agent in Microsoft Foundry, and govern your agents with Microsoft
Agent 365.

> New to the scenario? Start with the [Caldova background](../docs/README.md).

## What you'll explore

| Step | Product | Caldova scenario |
|---|---|---|
| 1 | Microsoft Copilot Studio | A supplier intelligence agent for Charlotte Waltson, VP of Procurement |
| 2 | Microsoft Foundry | An invoice assurance agent for Sarah Perez, AI App Developer |
| 3 | Microsoft Agent 365 | Enterprise agent operations for Carlos Slattery, CTO |

## Prerequisites

- Access to [Microsoft Copilot Studio](https://copilotstudio.microsoft.com).
- A [Microsoft Foundry](https://ai.azure.com) project.
- Admin access to the [Microsoft 365 admin center](https://admin.microsoft.com) with Agent 365.

## Steps

### 1. Build a conversational agent in Copilot Studio

1. Open [Copilot Studio](https://copilotstudio.microsoft.com) and create an agent.
2. Give it instructions (role, scope, tone, and safety rules), then add knowledge (docs, sites,
   and files) and tools for your business data.
3. Ask a business question that needs reasoning across documents, like Charlotte's:
   *"Which suppliers can take on additional tablet production, and which option requires the
   fewest contract changes?"*
4. Check that the answer cites the evidence behind its recommendation.

See [Demo 1](../delivery-resources/demos/demo-1-copilot-studio.md) for the expected result.
Go deeper with [Agent Academy](https://aka.ms/Agent-Academy).

### 2. Optimize an agent in Microsoft Foundry

1. Open your agent in the [Microsoft Foundry portal](https://ai.azure.com).
2. Review its **Traces** and **Evaluation** results to see quality, cost, and latency.
3. Turn production traces into a training dataset, then fine-tune a smaller model.
4. Compare the fine-tuned model with the original on quality and cost.

See [Demo 2](../delivery-resources/demos/demo-2-microsoft-foundry.md) for the scenario.
Go deeper with [Learn Microsoft Foundry](https://aka.ms/AITourFoundryIntro).

### 3. Observe and govern agents with Agent 365

1. As an admin, go to the [Microsoft 365 admin center](https://admin.microsoft.com) →
   **Agents** → **All agents** to see the agent registry.
2. Review each agent's owner, platform, status, and risks. Assign owners to ownerless agents.
3. Under **Settings**, review agent templates and agent management rules to apply guardrails and
   lifecycle policies.
4. Use Microsoft Purview to review agent activity for audit and compliance.

See [Demo 3](../delivery-resources/demos/demo-3-agent-365.md) for the capabilities covered.
Go deeper with [Learn Agent 365](https://aka.ms/A365Learn).
