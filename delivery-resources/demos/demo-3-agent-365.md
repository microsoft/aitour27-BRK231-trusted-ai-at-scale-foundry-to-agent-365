## What this demo shows

Caldova's useful agents become an enterprise-wide question. Every department is building
agents, and Carlos Slattery, Chief Technology Officer, owns the operating model for all of them:

> How do we observe, govern, and secure every agent across Caldova?
>
> Which agents create value, which create risk, and which should be retired?

Agent 365 is the control plane for agents:

- **Observe** — see every agent, its owner, usage, behavior, and connections.
- **Govern** — apply onboarding, access, policy, audit, and lifecycle controls.
- **Secure** — protect identities and data, detect risk, and investigate threats.

Capabilities covered in this act:

| Pillar | Capability | Status in deck |

| Observe | Register and track agents across your organization (agent registry) | Generally available |
| Observe | Detect popular agents to control shadow AI | Frontier / public preview |

| Govern | Automate ongoing agent governance (agent management rules) | Generally available |
| Govern | Be audit-ready from the start (Microsoft Purview audit) | Generally available |
